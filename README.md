## JavaScript-функционал

В `script.js` реализованы:

1. Мобильное меню с открытием/закрытием и поддержкой `Escape`.
2. Аккордеон опыта работы: раскрывается один блок за раз.
3. Scroll-reveal анимация через `IntersectionObserver`.
4. Индикатор прогресса чтения страницы в верхней части окна.
